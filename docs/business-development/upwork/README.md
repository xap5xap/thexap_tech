# Upwork research and proposals

This folder is the durable record for Upwork research, shortlisted jobs, application drafts, and confirmed outcomes.

## Writing style

- Cut to the chase.
- Keep responses and drafts simple.
- Write like you are helping a friend, not preparing formal business copy.
- Use only the details needed to answer the client's question.
- Prefer concrete examples over broad claims.
- Do not use em dashes.

These rules apply to cover letters, screening answers, proposal drafts, tracker notes, daily research, Linear updates, and assistant replies about this work.
