## Product and pilot

The client has already prepared a detailed V0.1 specification, CORE and Stretch scope, acceptance criteria, and a procurement package. The first release is a tablet-oriented responsive web application or PWA for technicians. The pilot is expected to cover about 100 RV assets during 60 to 90 days of real field-service use.

The application must give each RV a persistent technical record. The proposed data structure covers owners, ownership periods, assets, systems, components, service events, findings, measurements, recommendations, and evidence. Component replacement must preserve the removed component and its service history while marking the replacement as active.

The V0.1 scope includes authentication, roles, an Asset 360 view, system and component navigation, structured service events and measurements, findings, recommendations, photo and document evidence, provenance, audit and correction history, an admin area, CSV migration, managed hosting, backups, data export, and production handoff.

Jobber remains responsible for scheduling, jobs, estimates, invoices, and payments. V0.1 does not require a custom Jobber API integration. A one-time CSV export will seed basic customer and RV records.
