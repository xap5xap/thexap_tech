## Requested outcome

Secret World is described as a live neighborhood map where people can complete small jobs, sell through popups and storefronts, and use local-business deals. The backend already exists and the new interface designs are in Figma.

The contractor is expected to:

1. Implement the finished screens with close visual fidelity.
2. Connect the new screens to existing APIs.
3. Build new APIs when required.
4. Diagnose and fix bugs across the interface, API, and database.
5. Deliver working code in the client's repository with a short change and fix summary.
6. Communicate in English and provide a short daily update.

The listing names Node.js, Express, MongoDB, Mongoose, JWT, bcrypt, rate limiting, Socket.io, AWS S3, Nodemailer, Multer, Joi, Axios, Node-cron, PM2, and Swagger. It appears to name React for web and mobile, but the text still contains a confirmation placeholder. The exact screen list also remains a placeholder.
