# Daily Upwork research notes

This folder stores dated, read-only opportunity research. Use one file per research day, named `YYYY-MM-DD.md`.

Each note should record:

- the search window and query families;
- each new job's direct URL and Upwork job ID;
- posting age, location, compensation, client activity, and competition when visible;
- the problem, responsibilities, fit, proof gaps, and recommendation;
- deduplication against the opportunity tracker and earlier daily notes;
- listings that closed or changed materially.

Do not infer an application or outcome from research. The [opportunity tracker](../opportunity-tracker.md) remains the current status record.
